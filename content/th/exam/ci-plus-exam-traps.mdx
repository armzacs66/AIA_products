# จุดที่มักสับสนในการสอบ CI Plus

| กรณี | ตามโน้ตนี้ |
| --- | --- |
| มะเร็งระยะลุกลาม | คุ้มครอง |
| มะเร็งระยะ 0 | ไม่คุ้มครอง |
| โรคหลอดเลือดสมอง | คุ้มครอง |
| ภาวะสมองขาดเลือดชั่วคราว (TIA) | ไม่คุ้มครอง |
| การผ่าตัด CABG | คุ้มครอง |
| การทำบอลลูน | ไม่คุ้มครอง |
| การใส่ขดลวด (Stent) | ไม่คุ้มครอง |
| การผ่าตัดลิ้นหัวใจแบบเปิด | คุ้มครอง |
| การเปลี่ยนลิ้นหัวใจผ่านสายสวน (TAVI) | ไม่คุ้มครอง |

## ระยะเวลารอคอย

60 วัน

## HIV

ไม่คุ้มครอง ยกเว้นกรณีที่ระบุไว้:

- ติดเชื้อ HIV จากการรับเลือด
- ติดเชื้อ HIV จากการปฏิบัติงาน

ตรวจสอบคำจำกัดความและข้อยกเว้นในกรมธรรม์ฉบับล่าสุดก่อนใช้อ้างอิง
