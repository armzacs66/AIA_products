# จุดที่มักสับสนในการสอบ CI Plus

| กรณี | ตามโน้ตนี้ |
| --- | --- |
| มะเร็งระยะลุกลาม | คุ้มครอง |
| มะเร็งระยะ 0 | ไม่คุ้มครอง |
| โรคหลอดเลือดสมอง | คุ้มครอง |
| ภาวะสมองขาดเลือดชั่วคราว (TIA) | ไม่คุ้มครอง |
| การผ่าตัด CABG | คุ้มครอง |
| การทำบอลลูน | ไม่คุ้มครอง |
| การใส่ขดลวด (Stent) | ไม่คุ้มครอง |
| การผ่าตัดลิ้นหัวใจแบบเปิด | คุ้มครอง |
| การเปลี่ยนลิ้นหัวใจผ่านสายสวน (TAVI) | ไม่คุ้มครอง |

## ระยะเวลารอคอย

60 วัน

## HIV

ไม่คุ้มครอง ยกเว้นกรณีที่ระบุไว้:

- ติดเชื้อ HIV จากการรับเลือด
- ติดเชื้อ HIV จากการปฏิบัติงาน

## จุดที่มักสับสนเพิ่มเติม

- เอกสารต้นทางอธิบายว่าอาจจ่ายผลประโยชน์โรคร้ายแรงครั้งเดียวหรือผลประโยชน์กรณีเสียชีวิต ไม่ใช่เงินชดเชยรายวันหรือการเบิกค่ารักษาพยาบาล
- โรคร้ายแรงสำหรับเด็กเป็นกลุ่มแยก เอกสารต้นทางระบุว่าคุ้มครองก่อนอายุ 17 ปี ทั้งนี้ให้ยึดนิยามในกรมธรรม์
- นิยามโรคหลอดเลือดสมองต้องมีอาการทางระบบประสาทต่อเนื่อง ไม่ใช่อาการชั่วคราว โดยเอกสารต้นทางระบุว่าไม่รวม TIA
- ตัวอย่างการผ่าตัดหัวใจที่เข้าเงื่อนไขต้องเป็นไปตามนิยาม ไม่ควรเหมารวมการทำบอลลูน การใส่ขดลวด หรือ TAVI
- เอกสารต้นทางระบุโรคที่เป็นมาก่อนและการทำร้ายตนเองโดยเจตนาเป็นข้อยกเว้น และโรคบางรายการมีข้อจำกัดด้านอายุ

## คำถามทบทวน

1. ระยะเวลารอคอยที่ระบุคือกี่วัน? **60 วัน**
2. TIA ถือเป็นตัวอย่างโรคหลอดเลือดสมองที่คุ้มครองในโน้ตนี้หรือไม่? **ไม่ถือ**
3. CI Plus จ่ายเงินชดเชยรายวันหรือไม่? **ไม่ เอกสารต้นทางระบุเป็นผลประโยชน์ครั้งเดียว**
4. กลุ่มโรคร้ายแรงสำหรับเด็กมีจำนวนกี่โรค? **4 โรค และเอกสารต้นทางระบุข้อจำกัดก่อนอายุ 17 ปี**

ตรวจสอบคำจำกัดความและข้อยกเว้นในกรมธรรม์ฉบับล่าสุดก่อนใช้อ้างอิง
