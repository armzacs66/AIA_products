# WPCI

## คำจำกัดความ

สัญญาเพิ่มเติมยกเว้นเบี้ยประกันกรณีโรคร้ายแรง

## ความคุ้มครอง

โรคร้ายแรงระยะรุนแรง 40 โรค

## ระยะเวลารอคอย

60 วัน

## สรุปข้อมูล

| รายการ | สรุปจากเอกสารประกอบการศึกษา |
| --- | --- |
| เหตุที่เข้าเงื่อนไข | ได้รับการวินิจฉัยครั้งแรกขณะยังมีชีวิตว่าเป็นโรคร้ายแรงที่เข้าเกณฑ์ |
| จำนวนโรค | เอกสารต้นทางระบุโรคร้ายแรงระยะรุนแรง 40 โรค |
| ระยะเวลารอคอย | 60 วัน |
| เบี้ยที่ได้รับการยกเว้น | เบี้ยในอนาคตของกรมธรรม์หลักจนครบกำหนดชำระเบี้ย |
| เบี้ย WPCI | เอกสารระบุว่าคงที่ตลอดระยะเวลาชำระเบี้ย |
| สัญญาเพิ่มเติมอื่น | อาจคงอยู่ได้หากชำระเบี้ยของสัญญานั้นต่อไป |
| อายุรับประกันภัยตามเอกสาร | 16-75 ปี; ตรวจสอบรุ่นกรมธรรม์ปัจจุบัน |
| สิทธิภาษี | เอกสารต้นทางระบุว่าเบี้ย WPCI ใช้ลดหย่อนภาษีบุคคลธรรมดาไม่ได้ |

## ผลประโยชน์

- เมื่อเข้าเงื่อนไขการเรียกร้องสินไหม จะยกเว้นเบี้ยในอนาคตของกรมธรรม์หลักตามที่เอกสารประกอบการศึกษาระบุ
- เอกสารต้นทางระบุว่าเบี้ย WPCI คงที่ตลอดระยะเวลาชำระเบี้ย และสัญญาเพิ่มเติมอื่นอาจคงอยู่ได้หากชำระเบี้ยของสัญญานั้นต่อไป
- WPCI แตกต่างจาก CI Plus: WPCI ยกเว้นเบี้ยประกัน ส่วน CI Plus จ่ายผลประโยชน์กรณีโรคร้ายแรง
- เอกสารต้นทางระบุว่า WPCI เป็นสัญญาเพิ่มเติมที่เลือกซื้อแนบและชำระเบี้ยแยก
- การยกเว้นเบี้ยเริ่มจากงวดถัดไปและดำเนินต่อจนสิ้นสุดระยะเวลาชำระเบี้ยของกรมธรรม์หลัก ตามที่เอกสารต้นทางสรุปไว้

## จำสำหรับสอบ

- WPCI = โรคร้ายแรง
- WP = ทุพพลภาพ

ตรวจสอบรายชื่อโรค ข้อยกเว้น เงื่อนไขการเรียกร้อง และสิทธิภาษีจากกรมธรรม์ WPCI ฉบับปัจจุบัน
