# Waiver of Premium (WP)

## คำจำกัดความ

สัญญาเพิ่มเติมยกเว้นเบี้ยประกันกรณีทุพพลภาพถาวรสิ้นเชิง (Total and Permanent Disability)

## เงื่อนไข

- ทุพพลภาพถาวร
- เกิดขึ้นก่อนอายุ 60 ปี

## สรุปข้อมูล

| รายการ | สรุปจากเอกสารประกอบการศึกษา |
| --- | --- |
| เหตุที่เข้าเงื่อนไข | ทุพพลภาพถาวรสิ้นเชิงตามคำนิยามกรมธรรม์ |
| เงื่อนไขอายุ | เอกสารระบุว่าเกิดก่อนอายุ 60 ปี |
| ระยะเวลาของภาวะ | เอกสารระบุอย่างน้อย 180 วัน ให้ตรวจสอบคำนิยามฉบับจริง |
| เบี้ยที่ได้รับการยกเว้น | เบี้ยส่วนที่เข้าเงื่อนไขของกรมธรรม์หลักเท่านั้น |
| กรมธรรม์หลัก | ยังคงมีผลหลังได้รับอนุมัติยกเว้นเบี้ย |
| สัญญาเพิ่มเติมอื่น | ไม่ได้รวมอยู่ในการยกเว้นโดยอัตโนมัติ และบางฉบับอาจสิ้นสุดตามเงื่อนไขของตน |
| การแนบสัญญา | บางแบบอาจรวม WP ไว้ภายใต้เงื่อนไขบริษัท; เอกสารระบุวงเงิน 4 ล้านบาทสำหรับ Endowment 15/25 |

## ผลประโยชน์

- ยกเว้นเบี้ยประกันส่วนที่เข้าเงื่อนไขของกรมธรรม์หลัก หลังบริษัทอนุมัติการเรียกร้องสินไหม
- เอกสารประกอบการศึกษาระบุกรณีทุพพลภาพถาวรสิ้นเชิงก่อนอายุ 60 ปี และมีภาวะต่อเนื่องอย่างน้อย 180 วันตามคำนิยามในกรมธรรม์
- โดยทั่วไป WP ไม่ได้ยกเว้นเบี้ยของสัญญาเพิ่มเติมอื่น เอกสารต้นทางเตือนว่าสัญญาเพิ่มเติมบางฉบับอาจสิ้นผลเมื่อได้รับอนุมัติยกเว้นเบี้ยและอาจคืนเบี้ยส่วนที่ยังไม่คุ้มครอง จึงควรตรวจสอบเงื่อนไขของแต่ละฉบับ
- เอกสารต้นทางระบุว่า WP อาจรวมอยู่ในแบบประกันหลักบางแบบ โดยไม่จำเป็นต้องซื้อแยกทุกกรณี
- เบี้ยอาจมีสิทธิลดหย่อนภาษีตามหลักเกณฑ์ภาษีที่ใช้บังคับ ควรตรวจสอบกับแนวทางกรมสรรพากรฉบับปัจจุบัน

## จำสำหรับสอบ

WP = ทุพพลภาพ

เหตุที่เข้าเงื่อนไข ระยะเวลารอคอย เบี้ยที่ได้รับการยกเว้น และผลต่อสัญญาเพิ่มเติมอื่น ให้ยึดตามกรมธรรม์และรุ่นผลิตภัณฑ์
