## ⚖️ ลักษณะของสัญญาประกันภัย

1. ต่างตอบแทน
2. เสี่ยงโชค
3. สุจริตอย่างยิ่ง
4. ไม่มีแบบ แต่ต้องมีหลักฐานเป็นหนังสือลงลายมือชื่อผู้ต้องรับผิด จึงฟ้องร้องได้
5. มีหน่วยราชการควบคุม

## สัญญาเกิดเมื่อใด และต้องมีอะไรบ้าง

- สัญญาประกันชีวิตเกิดเมื่อผู้รับประกันตกลงรับตามคำเสนอ หรือผู้เอาประกันตกลงรับข้อเสนอเพิ่มเบี้ย (Substandard)
- ผู้รับประกันส่งมอบกรมธรรม์ 1 ฉบับและชดใช้เงินตามสัญญา กรมธรรม์ผู้รับประกันลงลายมือชื่อ ใบคำขอผู้เอาประกันลงลายมือชื่อ
- รายการในกรมธรรม์ 5 อย่าง
  1. วัตถุที่เอาประกัน
  2. ภัยที่รับเสี่ยง
  3. จำนวนเงินเอาประกัน
  4. จำนวนเบี้ยและวิธีส่ง
  5. เวลาเริ่มต้นและสิ้นสุด

## หน้าที่เปิดเผยความจริง

เริ่มตั้งแต่ทำคำเสนอขอเอาประกัน และมีตลอดไปจนกว่าผู้รับประกันตอบสนองคำเสนอ

## ปกปิดหรือแถลงเท็จ: ผลทางกฎหมาย

| สถานการณ์ | ผล |
|---|---|
| ปกปิดหรือแถลงเท็จสาระสำคัญ | สัญญาเป็นโมฆียะ ผู้รับประกันบอกล้างได้ |
| ผู้รับประกันรู้หรือควรรู้ว่าเท็จแต่ยังรับประกัน (ไม่สุจริตทั้งสองฝ่าย) | สัญญาสมบูรณ์ ผูกพันคู่สัญญา |
| แถลงอายุต่ำกว่าจริง | ลดทุนประกันลงตามส่วน |
| แถลงอายุสูงกว่าจริง | คืนเบี้ยส่วนเกิน |
| อายุจริงอยู่นอกเกณฑ์รับประกัน | โมฆียะ คืนมูลค่าไถ่ถอนกรมธรรม์ |

**เวลาบอกล้าง** ต้องใช้สิทธิภายใน **1 เดือน** นับแต่วันที่ทราบมูลอันจะบอกล้าง ไม่เช่นนั้นสิทธิระงับ

**ประกันอุตสาหกรรม** บริษัทปฏิเสธการจ่ายเพราะปกปิดได้ภายใน 2 ปีนับแต่ทำสัญญา

### โจทย์สถานการณ์จากสไลด์

- ปกปิดวัณโรค บอกล้างได้
- ป่วยโรคหัวใจโดยไม่ทราบมาก่อน แล้วบอกล้างหลังทำสัญญาไปแล้ว 1 ปี
- ปกปิดแผลมีดบาดที่ไม่กระทบความเสี่ยง
- ต่ออายุกรมธรรม์ที่ขาดอายุโดยปกปิดความดันสูง
- ปกปิดความดันสูงแต่เสียชีวิตจากอุบัติเหตุในปีที่ 1 ตามสไลด์จ่ายเฉพาะทุนอุบัติเหตุ

*ตัวอย่างที่ไม่มีเฉลยชัดในภาพ ให้ตรวจกับผู้บรรยายอีกครั้ง*

## ผู้รับประโยชน์

- ผู้รับประโยชน์คือบุคคลผู้จะพึงได้รับเงินใช้จากผู้รับประกันภัย จะเป็นใครก็ได้
- เปลี่ยนผู้รับประโยชน์ได้ เว้นแต่ได้ส่งมอบกรมธรรม์ให้ผู้รับประโยชน์ และผู้รับประโยชน์บอกกล่าวเป็นหนังสือถึงผู้รับประกันแล้ว
- ถ้าผู้รับประโยชน์เป็นผู้เยาว์ จ่ายแก่ผู้แทนโดยชอบธรรมตามที่ระบุ หรือตามคำสั่งศาล
- ผู้รับประโยชน์ฆ่าผู้เอาประกันโดยเจตนา ไม่จ่ายทุน แต่คืนเงินไถ่ถอนกรมธรรม์แก่ทายาท
- ประโยชน์ของการระบุชื่อ: สะดวกเรียกร้อง เงินไม่ตกเป็นของกองมรดก กำหนดสัดส่วนเมื่อมีหลายคน
- สิทธิของเจ้าหนี้
  - ระบุผู้รับประโยชน์เจาะจง: เรียกได้เท่าเบี้ยประกัน
  - ไม่ระบุ: เจ้าหนี้เรียกตามมูลหนี้จากกองมรดก
  - ระบุเจ้าหนี้เป็นผู้รับประโยชน์: ได้เงินตามกรมธรรม์

## 🧩 ส่วนได้เสีย (Insurable Interest)

**ส่วนได้เสีย** คือความสัมพันธ์ที่ทำให้ผู้เอาประกัน "เสียประโยชน์จริง" หากผู้ถูกเอาประกันเสียชีวิต ถ้าไม่มีส่วนได้เสีย การประกันก็กลายเป็นการพนันเอาชีวิตคนอื่น กฎหมายจึงกำหนดว่าต้องมี

- **ประกันชีวิต** ต้องมีส่วนได้เสีย **ตอนทำสัญญา** (ตามสไลด์คือ "ปีแรกในใบคำขอเท่านั้น") ถ้าภายหลังไม่มีแล้ว สัญญาก็ยังใช้บังคับได้
- **ประกันวินาศภัย** ต้องมีส่วนได้เสีย **ตลอดอายุสัญญา** จึงต่างกัน

<Callout tone="trap">ข้อสอบชอบถามว่า "หย่าแล้ว สัญญายังใช้ได้ไหม" คำตอบคือ <Tip text="สามีมีส่วนได้เสียในชีวิตภรรยาขณะทำสัญญา แม้ภายหลังหย่า สัญญาก็ไม่เสียไป">ยังใช้ได้ บริษัทปฏิเสธไม่ได้</Tip> เพราะดูที่เวลาทำสัญญา</Callout>

### ใครมีส่วนได้เสียในใคร

สไลด์ในชั้นอบรมไม่ได้ลงรายชื่อไว้ ตารางนี้เป็นหลักทั่วไปตามตำรา ควรเทียบกับผู้บรรยายหรือตัวบทก่อนใช้ท่องสอบ

| ผู้เอาประกัน | ผู้ถูกเอาประกัน | ส่วนได้เสีย |
|---|---|---|
| 🧍 ตนเอง | ตนเอง | มีเสมอ ไม่จำกัด |
| 💑 สามีหรือภรรยา | คู่สมรส | มี |
| 👨‍👩‍👧 บิดามารดา | บุตร | มี |
| 👶 บุตร | บิดามารดา | มี |
| 🏢 นายจ้าง | ลูกจ้าง | มี (คนสำคัญของกิจการ หรือประกันกลุ่ม) |
| 🏦 เจ้าหนี้ | ลูกหนี้ | มี เท่ากับจำนวนหนี้ |
| 🙋 คนแปลกหน้า | ใครก็ตาม | ไม่มี สัญญาใช้ไม่ได้ |

<Callout tone="key">ประกันชีวิต<b>ผู้อื่น</b> ต้องได้รับความยินยอมเป็นหนังสือจากผู้ถูกเอาประกัน (หลักทั่วไป ตรวจกับตัวบทอีกครั้ง) เพราะเป็นชีวิตของเขา</Callout>

### สามบทบาทที่มักสับสน

| บทบาท | คือใคร | ตัวอย่าง |
|---|---|---|
| ผู้เอาประกัน | ผู้ทำสัญญากับบริษัท ผู้จ่ายเบี้ย | แม่ทำประกันให้ลูก แม่คือผู้เอาประกัน |
| ผู้ถูกเอาประกัน | ผู้ที่ชีวิตถูกเอาประกัน | ลูกคือผู้ถูกเอาประกัน |
| ผู้รับประโยชน์ | ผู้ได้รับเงินเมื่อเกิดเหตุ | แม่ หรือผู้ที่แม่ระบุไว้ |

| กรณี | ใครได้รับเงิน | ที่มา |
|---|---|---|
| ระบุผู้รับประโยชน์ไว้ แล้วผู้เอาประกันเสียชีวิต | ผู้รับประโยชน์ เงินไม่ตกเป็นของกองมรดก | สไลด์ |
| ไม่ได้ระบุผู้รับประโยชน์ | กองมรดก แบ่งตามทายาท เจ้าหนี้เรียกจากกองมรดกตามมูลหนี้ | สไลด์ |
| ระบุเจ้าหนี้เป็นผู้รับประโยชน์ | เจ้าหนี้ได้เงินตามกรมธรรม์ | สไลด์ |
| ระบุคนอื่นเจาะจง แต่ผู้เอาประกันเป็นหนี้เจ้าหนี้ | ผู้รับประโยชน์ได้เงินตามกรมธรรม์ ส่วนเจ้าหนี้เรียกได้เพียงเท่าเบี้ยประกันที่ชำระ | สไลด์ |
| ผู้รับประโยชน์เป็นผู้เยาว์ | จ่ายแก่ผู้แทนโดยชอบธรรมที่ระบุไว้ หรือตามคำสั่งศาล | สไลด์ |
| ผู้รับประโยชน์ฆ่าผู้เอาประกันโดยเจตนา | ไม่จ่ายทุนประกัน แต่คืนเงินไถ่ถอนกรมธรรม์ให้ทายาท | สไลด์ |
| หย่ากับคู่สมรสที่ถูกเอาประกัน แต่ยังจ่ายเบี้ยต่อโดยไม่แจ้งบริษัท | บริษัทปฏิเสธไม่ได้ เพราะมีส่วนได้เสียตอนทำสัญญา เงินจ่ายตามกรมธรรม์ให้ผู้รับประโยชน์ | สไลด์ |
| ผู้รับประโยชน์หลายคน | แบ่งตามสัดส่วนที่ระบุ ถ้าไม่ระบุสัดส่วน ให้ถือว่าแบ่งเท่ากัน (หลักทั่วไป) | สไลด์และหลักทั่วไป |
| อยากเปลี่ยนผู้รับประโยชน์ | เปลี่ยนได้ เว้นแต่ได้ส่งมอบกรมธรรม์ให้ผู้รับประโยชน์ และเขาบอกกล่าวเป็นหนังสือถึงบริษัทแล้ว | สไลด์ |
| ผู้รับประโยชน์ตายก่อนผู้เอาประกัน | ผู้เอาประกันระบุคนใหม่ได้ ถ้าไม่ระบุ เงินเข้ากองมรดก (หลักทั่วไป) | หลักทั่วไป |
| ปกปิดความจริงจนบริษัทบอกล้างสัญญา | บริษัทไม่ต้องจ่ายทุนประกัน (จะคืนมูลค่าไถ่ถอนหรือเบี้ยแค่ไหน ตรวจตัวบท) | หลักทั่วไป |

<Callout tone="tip">ท่องสั้น ๆ: <b>มีชื่อ = คนมีชื่อได้</b> · <b>ไม่มีชื่อ = เข้ากองมรดก</b> · <b>ผู้เยาว์ = จ่ายผู้แทน</b> · <b>ฆ่าเจตนา = ไม่ได้ทุน ทายาทได้มูลค่าไถ่ถอน</b></Callout>

คอลัมน์ "ที่มา" ระบุว่าเป็นข้อมูลจากสไลด์ในชั้นอบรม หรือหลักทั่วไปที่เสริมให้ครบ แถวที่เป็นหลักทั่วไปควรตรวจกับผู้บรรยายหรือตัวบทก่อนยึดเป็นคำตอบสอบ

## ประกันชีวิตเทียบกับประกันวินาศภัย

| | ประกันชีวิต | ประกันวินาศภัย |
|---|---|---|
| อายุกรมธรรม์ | ตามแบบ | 1 ปี |
| สินไหม | ตามทุนที่ตกลง | ตามความเสียหายจริง ไม่เกินทุน |
| ส่วนได้เสีย | ปีแรกในใบคำขอเท่านั้น | ตลอดสัญญา |
| รับช่วงสิทธิ | ไม่มี | มี |
| อายุความฟ้องร้อง | 10 ปี | 2 ปี |
| บอกเลิกก่อนเกิดภัย | | ได้เบี้ยคืนตามสัดส่วน |

## เมื่อเงินไม่มีผู้มารับ

บริษัทต้องรักษาเงินไว้จนหมดอายุความ 10 ปี แล้วโอนเข้ากองทุนประกันชีวิตภายใน 1 เดือนนับแต่วันหมดอายุความ

ส่งคืนกรมธรรม์ได้ภายใน **15 วัน** นับแต่ได้รับมอบกรมธรรม์ บริษัทคืนเบี้ยทั้งหมดหลังหักค่าธรรมเนียม 500 บาท (และค่าตรวจสุขภาพถ้ามี) ถ้าขายทางโทรศัพท์ (Tele Sale) ได้ 30 วัน และไม่หักค่าธรรมเนียม

ผู้เอาประกันบอกเลิกสัญญาได้โดยงดจ่ายเบี้ยงวดต่อไป จะแจ้งบริษัทหรือไม่ก็ได้

## ที่มาของเนื้อหา

สไลด์และเฉลยในชั้นอบรมรอบบ่าย เสียงบรรยายรอบบ่ายทั้งสองช่วงจะเพิ่มเมื่อถอดเสียงเสร็จ ตัวเลขมาตราต่าง ๆ ใน ป.พ.พ. ที่คู่มือ คปภ. ฉบับ 2556 อ้างถึง (เช่น ม.865) ควรเทียบกับตัวบทฉบับปัจจุบัน
