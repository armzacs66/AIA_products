# CI Plus Exam Traps

| Situation | In these study notes |
| --- | --- |
| Invasive Cancer | Covered |
| Stage 0 Cancer | Not covered |
| Stroke | Covered |
| TIA | Not covered |
| CABG | Covered |
| Balloon | Not covered |
| Stent | Not covered |
| Open Valve Surgery | Covered |
| TAVI | Not covered |

## Waiting Period

60 Days

## HIV

Not covered, with these listed exceptions:

- HIV from blood transfusion
- Occupational HIV

Always check the current policy definition and exclusions before relying on these examples.
